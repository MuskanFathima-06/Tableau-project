## 📌 Overview
This project demonstrates my ability to **clean data, prepare it for analysis, and build interactive dashboards in Tableau**.  
Using a real‑world dataset, I performed preprocessing in SQL/Excel to fix inconsistencies and then created **visualizations and dashboards** in Tableau to uncover meaningful insights.

---

## 🔧 Key Tasks
- **Data Preparation**
  - Cleaned raw data (handled nulls, standardized formats, dropped irrelevant fields).
  - Structured the dataset for Tableau import.
  - Ensured compatibility between multiple data sources.

- **Dashboard Development**
  - Built interactive charts (bar, line, scatter, maps).
  - Added filters and parameters for dynamic exploration.
  - Designed KPIs and summary cards to highlight trends and patterns.
  - Combined multiple sheets into a cohesive dashboard.
